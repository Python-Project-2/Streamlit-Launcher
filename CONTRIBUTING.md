# Contributing to Streamlit Launcher For VS Code

Thank you for your interest in contributing to **Streamlit Launcher For VS Code**! Your support keeps this project powerful and easy to use for developers analyzing CSV, TSV, and Excel files.

## How Can I Contribute?

### 1. Reporting Bugs
- Search existing issues/reports to ensure it hasn't been brought up.
- Open a new bug report with a clear title and description.
- Provide steps to reproduce the issue, along with details about your OS, VS Code version, and the version of the extension you are using.

### 2. Suggesting Features
- We love feature requests! Check the project timeline to see if your idea is already planned.
- Explain the visual layout or behavior of the feature, highlighting how it benefits data analysis, chart generation, or PDF exporting.

### 3. Submitting Pull Requests (Code Contributions)
- Fork the repository and create your branch from `main`.
- Write clean code, keeping formatting matching the project style.
- Ensure that parsing logic for `.csv`, `.tsv`, `.xlsx`, `.xls`, and `.xlsm` works flawlessly without causing workspace errors.
- Submit your pull request with a descriptive summary of your changes.

## Development & Communication
- By contributing code, you agree to license your work under the **MIT License**.
- Please uphold a respectful environment in all communications, as detailed in our `CODE_OF_CONDUCT.md`.

Let's build a more powerful interactive tool together!
