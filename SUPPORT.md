# Support Guide

Thank you for using **Streamlit Launcher**! We want to ensure you have the best possible experience when managing and launching your Streamlit applications within VS Code.

If you encounter any issues, have questions, or want to suggest new features, please use the channels outlined below.

## 1. Official Extension Registry & Documentation
Before opening a new ticket, please check the official extension page for documentation, updates, and configuration guidelines:
* **Open VSX Registry:** [https://open-vsx.org/extension/dwidevelopes/streamlit-launcher](https://open-vsx.org/extension/dwidevelopes/streamlit-launcher)

## 2. GitHub Issue Tracker
For technical bugs, errors, or feature requests, please submit an issue through our GitHub repository tracker. 
When creating an issue, please provide:
* A clear and descriptive title.
* Steps to reproduce the issue.
* Your operating system and VS Code / Streamlit versions.
* Any relevant error logs or screenshots.

## 3. Contact the Developer
If you need direct assistance or have questions regarding commercial usage, partnerships, or security vulnerabilities, you can reach out to the core developer:
* **Lead Maintainer:** Dwi Bakti N Dev
