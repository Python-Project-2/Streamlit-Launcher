Token untuk Compile MSI

Fitur Compile MSI di sidebar Date Skunder AI mengubah satu link website menjadi installer Windows (.msi). Setiap compile butuh token, dan token dibuat di halaman ini.

  • Wajib masuk dengan GoogleKlik ikon akun di kanan atas. Tiap akun bisa klaim 1 token gratis per hari. Generate manual: klik pertama mengunci 1 menit, klik kedua mengunci 30 hari.
  • 5 compile per 5 jamKuota dihitung per komputer. Satu compile memakai satu kuota.
  • Jeda 5 jam saat kuota habisCompile dan pembuatan token baru sama-sama menunggu sampai kuota di-reset otomatis.
  • Server hanya menyimpan hashSalinan teks token, statistik, dan daftar token disimpan per akun di Databases, bukan di browser, jadi tetap muncul setelah refresh dan bisa dilihat kembali. Hapus kapan saja lewat tombol Hapus.
  • Hanya berlaku di komputer iniMenutup VS Code tidak menghapus jatah yang sudah terpakai.
  1. 1Klik ikon akun di kanan atas, lalu Masuk dengan Google.
  2. 2Klik Generate token atau Klaim token gratis (sekali per hari).
  3. 3Tekan Salin token, lalu tempel di view Compile MSI. Isi link website, nama aplikasi, pengembang, versi, folder, dan icon.
  4. 4Klik ▶ Compile MSI. Kalau 5 kuota habis, tunggu 5 jam.

Isian di view Compile MSI

  • Link website: alamat yang akan dibungkus jadi aplikasi Windows.
  • Nama aplikasi dan pengembang: tampil di installer.
  • Versi: nomor versi installer.
  • Folder: lokasi hasil compile disimpan.
  • Icon: gambar untuk aplikasi hasil compile.
  • Verifikasi: cek token sebelum compile.

Membuka view Compile MSI

  • Tekan Ctrl+Alt+6, atau klik ikon Date Skunder di Activity Bar.
  • Pilih view Compile MSI. Server token menyala otomatis.
  • Kembali ke halaman ini, klik Generate token, lalu salin.

Tanya jawab

Masalah yang paling sering muncul.

Login Google gagal

Di Databases Console: (1) Authentication → Sign-in method → aktifkan Google. (2) Authentication → Settings → Authorized domains → tambahkan 127.0.0.1. (3) Buka halaman lewat http://127.0.0.1:47832/token.html, bukan berkas file. (4) Izinkan popup di browser. Firestore perlu rules yang mengizinkan dokumen users/{uid} beserta subkoleksi users/{uid}/tokens milik sendiri.

Kenapa tombol Generate terkunci 1 menit?

Satu klik membuat satu token dan memakai satu kuota. Kunci 1 menit mencegah klik berulang. Klik Generate kedua mengunci tombol 30 hari, dan token gratis harian tidak ikut terkunci.

Bagaimana klaim token gratis harian?

Setelah masuk, klik Klaim token gratis sekali per hari. Hari berganti pukul 00:00 waktu perangkat. Klaim tetap memakai kuota 5 compile per 5 jam. Kalau pembuatan gagal, klaim hari itu dikembalikan.

Di mana salinan token disimpan?

Di Databases Databases per akun Google: koleksi users/{uid}/tokens menyimpan 10 salinan terakhir (teks token, kuota percobaan, dan masa berlaku), sedangkan statistik, daftar token tersembunyi, dan kunci generate tersimpan di dokumen users/{uid}. Tidak ada lagi data yang disimpan di localStorage browser — sisa data lama otomatis dipindahkan ke Databases lalu dihapus saat login. Rules Databases yang dibutuhkan:

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{uid} {
      allow read, write: if request.auth != null && request.auth.uid == uid;
      match /tokens/{tid} {
        allow read, write: if request.auth != null && request.auth.uid == uid;
      }
    }
    match /community_diskusi/{mid} {
      allow read: if true;
      allow create: if request.auth != null;
    }
  }
}
Token hilang setelah refresh

Salinan teks token (10 terakhir) tersimpan di Databases per akun Google, jadi tetap muncul setelah refresh, ganti browser, atau ganti komputer — selama masuk dengan akun yang sama. Kalau tidak muncul, cek koneksi internet. Server lokal hanya menyimpan hash, jadi buat token baru bila perlu.

Tombol Generate token tidak bisa ditekan

Kuota compile di komputer ini sudah habis, atau Anda belum masuk. Hitung mundur reset tampil di panel.

Status "server lokal tidak terjangkau"

VS Code belum terbuka atau view Compile MSI belum dibuka. Buka view itu, lalu klik tombol muat ulang. Halaman mencari server di port 47832 sampai 47844.

Apakah token dikirim ke internet?

Token dibuat dan diperiksa oleh server lokal di 127.0.0.1. Salinan teks token, statistik, dan data akun disimpan di Databases untuk akun Anda supaya bisa dilihat kembali dari perangkat mana pun; verifikasi compile tetap terjadi lokal di komputer.

Bisakah token dipakai di komputer lain?

Tidak. Token hanya berlaku di komputer tempat token dibuat.
